# e-CF — notas internas de venta (no publicar como oferta en web)

**Estado:** la web **no** usa nombre comercial de paquete, bonos, plazos fijos ni garantías genéricas. El cierre es **diagnóstico + cotización** (calculadoras internas).

## Mensaje público (vigente)

- Conectar certificación **e-CF DGII** con la operación (pedido → factura → cobro → contabilidad).
- Migración de datos maestros incluida en el servicio e-CF acordado, no como SKU aparte.
- Si el **Facturador Gratuito** basta, decirlo (tabla en hub).

## Objeciones → respuesta (FAQ / llamadas)

Ver preguntas en `/facturacion-electronica/` (FAQ general). No copiar promesas de competidores (p. ej. prueba 15 días).
